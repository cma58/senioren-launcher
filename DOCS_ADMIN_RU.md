# 📖 Руководство для опекунов и семьи (v0.8.5)

**🌐 Язык:** [English](DOCS_ADMIN.md) · **Русский** · [Nederlands](DOCS_BEHEERDER_NL.md)

Добро пожаловать в Senioren Launcher. Это руководство предназначено для членов семьи, опекунов и администраторов. Лаунчер полностью готов к **Android 16 (Baklava)** и соответствует строгому европейскому законодательству о защите данных (**GDPR**).

---

## 🛠️ 0. Первая установка (мастер настройки)
1.  **Выберите язык:** самый первый экран предлагает выбрать язык (Русский, Nederlands, ...). По умолчанию выбран русский. Позже язык можно изменить в разделе *«Настройки»*.
2.  **Примите заявление о конфиденциальности.**
3.  **Выберите роль:** *«Я опекун»* (техническая настройка) или *«Я пользователь»* (личный выбор пожилого человека).
4.  **Шаги для опекуна:** разрешения, системные разрешения, приложения по умолчанию (главный экран, телефон, SMS), основные контакты (до 4, они становятся избранными и SOS-контактами), обнаружение падения, PIN-код и удалённая помощь.
5.  **Передайте телефон пожилому человеку** — он выберет размер текста и цвета.

> **Совет:** все экраны настройки прокручиваются, а кнопка «Далее» остаётся внизу экрана даже при самом большом размере текста.

## 🔐 1. Авторизация: как стать администратором
Чтобы управлять телефоном удалённо, Ваш номер должен быть распознан как авторизованный SOS-контакт.

### Пошаговая инструкция:
1.  **Откройте «Контакты»:** на экране пожилого человека нажмите кнопку **«Контакты»**.
2.  **Добавьте контакт:** добавьте себя (или отредактируйте существующий контакт).
3.  **Отметка звёздочкой:** убедитесь, что Вы отмечены как **избранный / SOS-контакт** (обычно нажатием на звёздочку рядом с именем).
4.  **Распознавание номера:** введите свой номер. Приложение автоматически распознаёт все форматы:
    *   Локальный: `0487123456`
    *   Международный: `+32487123456` или `0032487123456`
5.  **Проверка:** отправьте со своего телефона SMS с текстом `#PING` на телефон пожилого человека. Если на его экране появилось подтверждение, связь установлена.

## 🏠 2. Настройка главного экрана
- **Сетка и размер текста:** *«Настройки»* (под PIN-кодом) → выберите 1x1, 2x3 или 3x4 и размер текста. Количество рядов плиток подстраивается под экран, поэтому ничего не обрезается. Лишние плитки переходят на страницы, которые можно листать (точки страниц под сеткой).
- **Изменение порядка плиток:** удерживайте плитку, затем сколько нужно раз нажимайте **«◀ Раньше»** или **«Позже ▶»** и в конце — **«ГОТОВО»**. В окне показано место плитки, например «Звонки: место 2 из 8».
- **Замена или удаление приложения:** в том же окне нажмите **«Заменить или убрать»** (для «Настроек», Wi-Fi и Bluetooth недоступно).
- **Язык:** *«Настройки»* → Язык. Приложение перезапустится и покажет новый язык.

## 📱 3. Конфиденциальность и безопасность (готово к Android 16)
Приложение построено по принципу **Privacy by Design**. Это значит:
*   **Метки конфиденциальности:** на экранах, где используются чувствительные данные (например, местоположение или контакты), пожилой человек теперь видит синий значок конфиденциальности с понятным объяснением, зачем нужны эти данные.
*   **Безопасные обновления:** обновления приложения загружаются по HTTPS и требуют явной проверки прав на установку — в соответствии с новейшими требованиями безопасности Android.
*   **Защита от мошенников:** лаунчер автоматически блокирует известные спам-номера и предупреждает о подозрительных SMS.

## 🎮 4. Удалённое управление по SMS (полный список)
Отправьте пожилому человеку SMS с одним из следующих кодов. Приложение отреагирует сразу. Коды всегда на нидерландском, независимо от языка приложения (полный список с пояснениями — в [COMMANDS_RU.md](COMMANDS_RU.md)).

| Категория | Код | Действие |
|:----------|:-----|:------|
| **Самочувствие** | `#WAAR` | Получить GPS-координаты в виде ссылки Google Maps. |
| | `#STATUS` | Проверить заряд батареи, уровень сигнала и громкость. |
| | `#PING` | Показать на экране крупными буквами «ALLES GOED?» («Всё в порядке?»). |
| | `#BEL_TERUG` | Телефон сразу перезванивает Вам. |
| **Помощь** | `#LAMP AAN` / `#LAMP UIT` | Включить / выключить фонарик удалённо. |
| | `#KNIPPER` | Заставить фонарик мигнуть 10 раз (чтобы найти телефон). |
| | `#ALARM [текст]` | Включить громкий сигнал с сообщением. |
| **Настройки** | `#VOLUME [1-15]` | Изменить громкость звонка (например, `#VOLUME 15`). |
| | `#HELDER [1-100]` | Изменить яркость экрана. |
| | `#WIFI AAN` / `#WIFI UIT` | Управлять подключением к интернету. |
| | `#STIL AAN` / `#STIL UIT` | Включить / выключить беззвучный режим («Не беспокоить»). |
| **Управление** | `#PRIVACY` | Получить обзор настроек конфиденциальности. |
| | `#UPDATE_CHECK` | Принудительно проверить наличие обновлений приложения. |
| | `#RESTART` | Перезапустить приложение-лаунчер. |
| | `#THEMA [1, 2 или 3]` | Сменить тему (1 — классическая, 2 — высокий контраст, 3 — светлая). |

## ❓ Часто задаваемые вопросы (FAQ)

**В: Почему телефон не реагирует на мои SMS?**
*   Проверьте, что Ваш номер есть в списке контактов со звёздочкой (SOS).
*   Убедитесь, что у пожилого человека есть средства на счёте для отправки ответного SMS.

**В: Можно ли назначить нескольких администраторов?**
*Да, любой контакт, отмеченный как SOS/избранный, может использовать команды.*

**В: Насколько точно определяется местоположение?**
*Приложение использует GPS. Если человек находится в помещении, точность может быть ниже. В SMS всегда указана ориентировочная погрешность в метрах.*

**В: Текст слишком крупный, и я не могу найти кнопку.**
*Экраны прокручиваются, а на главном экране при более крупном тексте показывается меньше рядов; листайте вбок, чтобы увидеть остальные плитки. Если текст всё равно слишком крупный, уменьшите размер текста в настройках или отправьте `#LETTER 3`.*

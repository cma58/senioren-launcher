# Участие в разработке Senioren Launcher

**🌐 Язык:** [English](CONTRIBUTING_EN.md) · **Русский** · [Nederlands](CONTRIBUTING.md)

Спасибо, что хотите помочь!

## Как внести вклад

### Сообщения об ошибках
Создайте issue по шаблону Bug Report.

### Вклад в код
1. Сделайте форк проекта
2. Создайте ветку: `git checkout -b feature/my-feature`
3. Сделайте коммит: `git commit -m 'Add X'`
4. Отправьте ветку: `git push origin feature/my-feature`
5. Откройте Pull Request

### Сборка
- Нужен JDK 17 (задайте `JAVA_HOME`).
- `./gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`) → `app/build/outputs/apk/debug/app-debug.apk`.
- Некоторые телефоны (например, Xiaomi/MIUI без SIM-карты) блокируют `adb install`; скопируйте APK на телефон и откройте его в приложении «Файлы».

### Перевод
Видимый пользователю текст хранится в файлах ресурсов, а не прямо в коде:
1. Нидерландский — язык по умолчанию: `app/src/main/res/values/strings.xml`, `strings_ui.xml` и `strings_tiles.xml`.
2. Русский находится в `app/src/main/res/values-ru/` (те же имена файлов). Используйте его как образец.
3. Для нового языка создайте папку `values-XX` (XX — код языка), скопируйте три файла и переведите все строки. Сохраняйте подстановки (`%1$s`, `%2$d`) и их нумерацию.
4. Добавьте код языка в `LocaleHelper.SUPPORTED` (`util/LocaleHelper.kt`) и в список языков в `SettingsScreen.kt`. Экран выбора языка при первом запуске использует `LocaleHelper.SUPPORTED`.
5. В коде используйте `i18n(R.string.key, args)` (работает в composable-функциях, сервисах и приёмниках) вместо строковых литералов. В composable-функциях подойдёт и `stringResource`.
6. **Не** переводите SMS-команды удалённого управления (`#WAAR`, `#PING`, ...). Это протокол между двумя приложениями.
7. Проверяйте при самом большом размере текста: русские и немецкие тексты длиннее нидерландских, их нельзя обрезать.

## Принципы дизайна
1. **Просто** — если бабушка не понимает, значит, слишком сложно
2. **Крупно** — всё должно читаться без очков и при любом размере текста (весь интерфейс масштабируется вместе с ним, поэтому экраны должны прокручиваться или подстраиваться, а не рассчитывать на фиксированный размер)
3. **Безопасно** — ни одно действие не должно «что-то сломать»; предпочитайте большие кнопки жестам вроде перетаскивания или удаления долгим нажатием
4. **Приватно** — ни одни данные не покидают устройство

## 🔗 The Ecosystem: How it works
The **Senioren Launcher** is part of a 2-app ecosystem designed for maximum safety.

1.  **Senioren Launcher** (this app): Installed on the **senior's phone**. It provides a simple, safe interface and executes remote commands.
2.  **[Senioren Beheerder](https://github.com/cma58/SeniorenBeheerder)**: Installed on the **caregiver's phone**. It acts as a remote control to monitor status, location, and settings via encrypted SMS commands.

---

## 🌟 Senior-First Design
Most smartphones are designed for young people. We turn that around. The Senioren Launcher is built following strict UX rules for the elderly:
- **No Keyboards:** Everything works with large buttons and simple lists.
- **Gigantic Elements:** High-contrast text (20-30sp) and oversized touch targets (70dp+).
- **Digital Peace:** Zero unnecessary notifications or complicated swipe gestures.

## ✨ Key Features
| Feature | Description |
| :--- | :--- |
| **📞 Simplified Calling** | Large dialer with photo favorites and a secure 112 emergency confirmation. |
| **💬 Message Center** | Extra-large SMS view with instant font size adjustment. |
| **🆘 Smart SOS** | Hold for 3 seconds to trigger emergency calls and GPS location sharing. |
| **💊 Medication Tracker** | Reminders with pill photos and automated stock tracking. |
| **🎮 Remote Support** | Allow caregivers to manage the phone via [Senioren Beheerder](https://github.com/cma58/SeniorenBeheerder). |

## 🛡️ Security & Privacy (Android 17 Ready)
Fully optimized for the latest Android standards and GDPR compliant:
- **Privacy by Design:** Explicit permission handling for Contacts and GPS.
- **100% Local:** Your data never leaves your device. No tracking, no data mining.
- **Modern Display:** Full Edge-to-Edge support for Android 15/16/17.
